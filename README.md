# Бот-предложка для Telegram-канала — готовый бот для botdepo

Подписчики присылают боту посты — текст, фото, видео, голосовые. Вы
получаете каждый с кнопками **«Опубликовать»** и **«Отклонить»**; одобренный
пост уходит в канал от имени канала (без «переслано от»), автору приходит
ответ, что решили.

Настраивать на сервере ничего не нужно: только токен от @BotFather. Остальное — командами прямо в чате с ботом.

## Запустить за минуту

1. Получите токен бота у [@BotFather](https://t.me/BotFather) в Telegram: `/newbot` → придумать имя → скопировать токен.
2. Зарегистрируйтесь на [botdepo.ru](https://botdepo.ru) → «Новый бот» → выберите «Предложка для канала» в готовых ботах
   (или вставьте ссылку на этот репозиторий в поле «Репозиторий»).
3. Вставьте токен и нажмите «Задеплоить». Через минуту бот работает.
4. **Сразу напишите своему боту `/start`** — кто напишет первым, тот и владелец.

## Как настроить

1. Напишите боту `/start` — станете владельцем.
2. Добавьте бота в свой канал администратором с правом **«Публикация сообщений»**.
   Бот сам запомнит канал и напишет вам. Подключить канал может только владелец.
3. Поставьте ссылку на бота в описание канала: «Предложить пост — @ваш_бот».

`/status` — какой канал подключён и сколько постов ждут проверки.
У одного человека может висеть не больше 5 непроверенных постов — защита от спама.

## Что где лежит

| Файл | Что внутри |
|---|---|
| `main.py` | бот: команды, кнопки, обработчики |
| `storage.py` | хранение данных в SQLite в `/data` |
| `requirements.txt` | библиотеки — по одной на строку |
| `AGENTS.md` | правила для ИИ-ассистентов |

## Поменять под себя

Нажмите **Use this template** вверху страницы — появится своя копия. В botdepo
создайте бота со ссылкой на неё (того, что запущен из этого репозитория,
удалите: один токен не может работать в двух ботах сразу). Меняйте код
прямо на GitHub и жмите «Передеплоить» в карточке бота.

Пишете с ИИ — ограничения платформы описаны в `AGENTS.md`, Cursor и Claude
Code читают его сами; в ChatGPT вставьте его в начало разговора.

## Где хранятся данные

В SQLite в папке `/data` — она переживает перезапуски и передеплои. Если
нужно сменить владельца, удалите бота в панели и создайте заново.

## Запустить у себя на компьютере

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
BOT_TOKEN=ваш_токен python main.py   # Windows: set BOT_TOKEN=ваш_токен && python main.py
```

Не запускайте бота одновременно у себя и на botdepo с одним токеном —
Telegram отдаёт сообщения только одной копии.

## Если что-то не работает

Логи и подсказки по ошибкам — в карточке бота на botdepo, разбор частых
ошибок — в [документации](https://botdepo.ru/docs#errors).
