# Правила для ИИ-ассистента

Этот бот запускается на хостинге botdepo (botdepo.ru). Код, который ты
пишешь, обязан соблюдать ограничения платформы — иначе бот не соберётся
или упадёт сразу после запуска.

## Ограничения платформы

- **Получение сообщений — только long polling.** Вебхуки не поддерживаются:
  входящих портов у бота нет. Не поднимай веб-сервер для приёма апдейтов.
- **Токен — из переменной окружения `BOT_TOKEN`.** Не хардкодь токены и
  ключи. Прочие секреты — тоже из переменных окружения (пользователь задаёт
  их в панели botdepo).
- **Писать на диск — только в `/data`.** Файловая система контейнера только
  для чтения, кроме `/data` (постоянная, переживает передеплой) и `/tmp`
  (64 МБ, очищается при перезапуске). Базы данных, файлы, логи — в `/data`.
  Используй SQLite или файлы; внешней базы данных у бота нет.
- **Все файлы — в корне репозитория.** Платформа ищет манифест и точку входа
  в корне, не во вложенных папках.
- **Ресурсы:** 256 МБ памяти, полпроцессора, до 128 процессов. Не загружай
  большие модели и датасеты в память.
- **Сеть:** исходящий интернет есть (API, HTTP-запросы). Доступа к локальной
  сети и к хосту нет.
- **Бот должен работать постоянно.** Если процесс завершился в первые 20 с,
  деплой считается упавшим; потом платформа перезапускает упавшего бота.
- **Логи — в stdout/stderr** (print / logging / console.log). Пользователь
  видит их в панели. Не печатай токены и секреты в лог.
- **Один токен — одна копия бота.** Нельзя одновременно запускать бота
  локально и на botdepo.

## Python

- Python 3.12. Зависимости — **только** в `requirements.txt` в корне, по
  одной на строку. Каждую новую импортируемую стороннюю библиотеку добавляй
  туда. Не ставь пакеты из кода (`pip install` в рантайме не сработает:
  сеть при сборке отключена, диск только для чтения).
- Точка входа — `main.py` в корне (платформа запускает `python main.py`).
- Путь к данным уже определён в `storage.py` (`DATA_DIR`) — используй его.

Библиотека — aiogram 3 (не 2.x: API несовместим).

## Перед тем как отдать код

Проверь: всё ли, что импортируется, перечислено в манифесте; нет ли записи
файлов вне `/data`; читается ли токен из `BOT_TOKEN`; нет ли вебхуков.
